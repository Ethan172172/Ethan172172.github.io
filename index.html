課程專案 多媒體程式設計 — 個人履歷網站與前端互動實作

在多媒體程式設計課程中，擔任網頁架構規劃與前端切版開發角色。從 Wireframe 設計出發，使用 HTML5 語義化標籤與純 CSS3 建立卡片式響應式版面，並整合 JavaScript 實作標籤切換、照片輪播與表單互動。透過這次實作，我學會了如何兼顧版面美感、程式碼縮排與 GitHub Pages 靜態網站部署流程。

佐證資料： 本網站即時展示 GitHub 儲存庫
校隊競技 中原大學大專籃球聯賽公開三級校隊成員

加入中原大學男子籃球校隊，擔任前鋒與中鋒位置，負責禁區卡位籃板、防守協防與快攻跟進。每週固定參與高強度夜間團隊訓練與重量訓練計畫，在緊湊的資管系課業與練球之間培養高度自律與時間管理能力，也深刻體會到團隊默契與臨場溝通的重要性。

佐證資料： 校隊訓練與生活紀錄
文學創作 2026 中原大學普仁文學獎短篇小說獲獎經歷

以中壢在地街巷日常與觀察視角為靈感，獨立完成短篇小說《第七位觀察者》與《回聲修補匠》的故事架構、角色塑造與文字修潤，並投稿參與校內普仁文學獎徵文比賽，最終榮獲短篇小說組第三名肯定。這段創作歷程大幅提升了我的敘事邏輯、細節觀察力與文字表達能力。

佐證資料： 普仁文學獎得獎收錄證明
